# Image Target 🖼️

## Description

This folder contains the **Image Target** used by the **AR Solar System Using Image Recognition** application.

The image target acts as a visual marker for the Augmented Reality system. The application uses image recognition to detect this predefined image through the device camera. Once the image is successfully recognized, the AR system places the virtual **3D Solar System** over the detected target.

## Purpose

The Image Target is used to:

- Detect and recognize the predefined image.
- Trigger the Augmented Reality experience.
- Provide a reference surface for displaying the 3D Solar System.
- Connect the real-world image with the virtual AR content.

## File

**`solar-system-target.jpg`**  
The target image used for image recognition in the AR Solar System application.

## How to Use

1. Download or open `solar-system-target.jpg`.
2. Display the image on a screen or print it on paper.
3. Open the **AR Solar System** application.
4. Point the device camera toward the image.
5. Allow the application to recognize the target.
6. Once detected, the 3D Solar System will appear in the Augmented Reality environment.
