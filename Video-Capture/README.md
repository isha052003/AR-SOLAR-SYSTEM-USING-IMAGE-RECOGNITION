# Video Capture 🎥

## Description

This folder contains a video demonstration of the **AR Solar System Using Image Recognition** application.

The video demonstrates the complete Augmented Reality experience, including image target detection and the display of the virtual 3D Solar System after successful recognition.

## Video Demonstration

The video shows:

- Detection of the predefined Image Target.
- Recognition of the target image by the application.
- Activation of the Augmented Reality environment.
- Display of the virtual 3D Solar System.
- Real-time interaction with the AR content.

## Video File

**`ar-solar-system-demo.mp4`**

The video provides a visual demonstration of how the application works in a real-world environment.

## Purpose

The video is included to provide practical evidence of the working AR application and to demonstrate the interaction between image recognition and Augmented Reality.
